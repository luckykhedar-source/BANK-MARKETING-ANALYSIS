\# 🏦 Bank Marketing Analytics \& Term Deposit Prediction



\## 📌 Project Overview



This project analyzes bank marketing campaign data to understand

customer demographics, loan behavior, campaign performance and

factors influencing term deposit subscriptions.



The project also develops machine learning classification models

to predict whether a customer is likely to subscribe to a term deposit.



\---



\## 🎯 Objectives



\- Clean and preprocess banking data

\- Handle missing and inconsistent values

\- Standardize categorical variables

\- Encode the target variable

\- Perform exploratory data analysis

\- Analyze customer demographics

\- Analyze housing and personal loans

\- Analyze marketing campaign performance

\- Perform hypothesis testing

\- Perform correlation analysis

\- Build classification models

\- Evaluate model performance

\- Generate business insights



\---



\## 📊 Dataset



Rows: 45,211



Columns: 17



Target Variable:



`y`



\- 0 = No

\- 1 = Yes
